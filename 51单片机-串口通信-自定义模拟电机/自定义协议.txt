
#### 1. 设置速度

发送：

```
SET_VEL 10
```

返回：

```
CMD:SET_VEL 10
OK SET_VEL
```
#### 2. 设置位置

发送：

```
SET_POS 100
```

返回：

```
CMD:SET_POS 100
OK SET_POS
```
#### 3. 查询状态

快速发送：

```
STATUS
```

可能：

```
TARGET:100 POS:20 VEL:10
```

继续：

```
TARGET:100 POS:60 VEL:10
```

最后：

```
TARGET:100 POS:100 VEL:0
```
#### 4. 查询位置

发送：

```
GET_POS
```

返回：

```
POS:100
```
#### 5. 查询速度

运动过程中：

```
GET_VEL
```

返回：

```
VEL:10
```

停止后：

```
VEL:0
```
